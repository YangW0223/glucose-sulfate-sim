# 葡萄糖中硫酸盐检查 · Web 3D 高拟真实验 PoC

基于 React + TypeScript + React Three Fiber + Three.js + Rapier + Zustand 的浏览器 3D 实验仿真项目。

目标不是“点击下一步播放动画”，而是在同一个实验操作台中自由拿取、移动、称量、吸液、放液和倾倒，并让质量、体积、轨迹、洒落与实验误差由当前仿真状态连续计算产生。

## 包管理

统一使用 **pnpm 12.4.2**（项目 `package.json` 已锁定 `packageManager: pnpm@12.4.2`）：

```bash
pnpm install
pnpm dev
```

构建：

```bash
pnpm build
```

不要混用 npm/yarn 锁文件。

## 本轮界面优化：深色实验台 + 仪器架真实陈列

根据实际页面反馈，本轮对实验场景做了两项直接调整：

- 实验台与仪器架使用更深的赭黄 / 芥末黄配色，与透明玻璃和浅蓝背景形成明显冷暖对比；
- 当前已经实现的仪器不再全部初始化在实验台上，而是按上下两层真实陈列在仪器架中，电子天平保留在实验台。

当前仪器架初始陈列包括：

```text
上层：供试纳氏比色管 / 对照纳氏比色管 / 5 ml 刻度吸管 / 洗耳球 / 药勺 / 称量纸
下层：250 ml 洗瓶 / 100 ml 标准液容量瓶 / 50 ml 量筒 / 葡萄糖试剂瓶
实验台：电子天平
```

所有归位坐标集中在：

```text
src/scene/labLayout.ts
```

执行“重置实验”后，各器材会回到仪器架对应位置，而不是重新堆到实验台。葡萄糖试剂瓶也已从固定场景物体升级为可拿取物体，可以从仪器架拖到实验操作台后再进行取样。

## 本轮升级：玻璃可读性 + 真实电子天平 + 架子到实验台拿取

本轮针对实际页面反馈继续做了三项核心升级：

1. **玻璃不再“透明到看不见”**：仍使用 `MeshPhysicalMaterial` 的 transmission / IOR / thickness 表现玻璃，但 transmission 降低到更适合教学仿真的范围，并加强吸收色、clearcoat、环境反射和结构轮廓。悬停或拿起时会进一步增强边缘与体积感。
2. **电子天平重做**：不再只展示一个简单白盒模型，改为带不锈钢秤盘、圆形盘座、嵌入 LCD、CAL/TARE 实体按键、橡胶脚、水平泡和仪器铭牌的实验室电子天平外观。天平数据逻辑仍保持真实去皮与连续稳定读数。
3. **完整“仪器架 → 实验台”拿取链路**：鼠标悬停器材会高亮并显示抓取光标；按住拖动后仪器进入拿取状态，实验台出现黄色放置边界与当前器材提示；拖入实验台范围后松开会稳定放置到台面。称量纸拖到天平秤盘附近时会优先吸附到秤盘，而不是落到普通台面。

新增关键文件：

```text
src/interaction/workbenchPlacement.ts
src/scene/WorkbenchDropZone.tsx
```

当前操作建议：

```text
鼠标移到架上器材
→ 器材轮廓增强 / 光标变为 grab
→ 按住拖动
→ 黄色实验台放置边界出现
→ 移入边界
→ 松开鼠标
→ 器材稳定落到实验台
```

## 本轮新增：对照液与 5 ml 刻度吸管

现在已经加入实验文档下一段核心操作：

```text
100 ml 标准硫酸钾容量瓶
        ↓
连接洗耳球
        ↓
5 ml 刻度吸管尖端插入标准液
        ↓
按住 Space 连续吸液
        ↓
吸至 0 刻度
        ↓
移动至对照纳氏比色管
        ↓
滚轮调整吸管高度
        ↓
按住 Shift 连续放液
        ↓
刻度读数达到 2.00 ml 时停止
        ↓
对照管真实得到实际放出的标准液体积
```

## 当前已经实现的完整前半段流程

```text
称量纸 → 电子天平 → 去皮
        ↓
药勺 → 葡萄糖瓶 → 连续取粉
        ↓
药勺 → 称量纸 → 连续加粉
        ↓
自己控制至约 2.0 g
        ↓
称量纸 → 供试纳氏比色管
        ↓
洗瓶 → 50 ml 量筒
        ↓
量取约 40 ml 蒸馏水
        ↓
量筒 → 供试管
        ↓
洗耳球 → 5 ml 刻度吸管
        ↓
刻度吸管 → 100 ml 标准硫酸钾容量瓶
        ↓
Space 吸至 0 刻度
        ↓
吸管 → 对照管
        ↓
Shift 放至 2.00 ml 刻度
        ↓
洗瓶 → 50 ml 量筒重新量水
        ↓
量筒 → 对照管约至 40 ml
```

这些步骤都不会自动把结果修正到标准值。

## 操作方式

- 鼠标拖动：拿起并移动实验对象；
- 天平蓝色按钮：去皮；
- 药勺伸入葡萄糖瓶 + `Space`：取粉；
- 拿住药勺 + 滚轮：倾倒粉末；
- 拿住称量纸 + 滚轮：向供试管转移葡萄糖；
- 拿住洗瓶 + `Space`：挤压出水；
- 拿住 50 ml 量筒 + 滚轮：控制倾角；
- 拖动洗耳球到刻度吸管顶部：连接；
- 拿住刻度吸管 + 滚轮：控制吸管上下高度；
- 吸管尖端进入标准液 + `Space`：连续吸液；
- 吸管对准对照管 + `Shift`：连续放液；
- 空白区域拖动：调整观察视角。
